## About Me

Electronics & Telecommunication Engineering student who builds full-stack + ML systems — not tutorial projects.

I care about how systems are designed, not just whether they work. Every project I build is an attempt to solve a real problem with real architecture.

Currently focused on:
- **ML Systems** — pipelines that actually execute, evaluate, and adapt
- **Backend Engineering** — APIs that are designed, not just written
- **System thinking** — modules that connect, not just coexist

---

## What I'm Building

### [Aiverse](https://github.com/deepmhatre13/Aiverse) — ML Engineering Platform
> Train. Compete. Ship ML Systems.

A full-stack platform that bridges the gap between learning ML and shipping it. Real code execution in Docker sandboxes, ELO-based problem ranking, interactive experimentation lab, and an AI mentor.
